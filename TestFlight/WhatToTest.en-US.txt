Rapid release — IAMWATCH schedule and Coconut Grove dealers

This candidate intentionally excludes native analytics and guide notifications. Those features are preserved on the full-feature development branch for a later release. No analytics or notification opt-in is needed for this update.

Minimum check:
1. Events → Singapore → IAMWATCH: Schedule opens first. Change the day, search for a speaker, and open Session details. All program times are Singapore local time.
2. Events → Miami → Coconut Grove: dealers appear vertically in A–Z order. Search for a dealer.
3. Mark a brand seen, check My list, briefly go offline and confirm saved guide/checklist/program content remains accessible. The program must have been loaded first.

Program content is read from the published WatchWeeks IAMWATCH page because API v1 currently has no program records. It is rendered natively without running website scripts. A failed refresh retains the last saved program. No fictional or test program is shipped.

Please report the exact version/build and any issue. This build is not submitted for App Review or released automatically.
